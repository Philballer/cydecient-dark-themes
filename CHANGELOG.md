# Changelog

## 1.0.6

- Search terms: description and tags now name every world color and the One Dark family, so the pack is found by the words people actually search.

## 1.0.5

- Title bar and status bar share the editor color in every world, as in One Dark Blue; no dark bands at the top and bottom.

## 1.0.4

- Each world described in the Overview: background, accent and what it feels like.

## 1.0.3

- The base theme is named by its published name, One Dark Blue, with a link to it.

## 1.0.2

- Description and README rewritten in the author's own voice: why this pack exists.

## 1.0.1

- Every world now copies One Dark Blue's exact chrome relationships: soft sidebar text and icons, no tab or panel accent lines, quiet list selections, near-invisible current line, dim line numbers and guides, dark buttons.

## 1.0.0

- First release: eleven worlds (Nature, Retro, Crimson, Obsidian, Blue, Light, Coffee, Violet, Gamer, Ember, Abyss), one shared code palette.
